Reviewed the committed PAPER-04 and FILES-01 work plus the uncommitted CHAT-01,

Preserved that work. No commit, push, dependency installation, or hosted database

## Verified issues and fixes

| Area | Finding | Correction |
| --- | --- | --- |
| Chat history/live inserts | RPC returned the oldest rows; the subscription looked for new IDs among only five old messages. | Latest bounded window in reading order; events trigger serialized snapshot reconciliation. |
| Chat state | Initial reads could replace newer events; switching channels showed old messages; reconnects did not reconcile. | Abort obsolete reads, queue refreshes, clear the feed on channel change, refresh after connection/focus, preserve channel drafts. |
| Chat permissions | Direct UPDATE could rewrite content/attribution; demoted senders could delete old messages. | Deny UPDATE, restrict INSERT columns, require an active owner/member for mutations. |
| Chat claims | Online/seen counts were fabricated; several enabled controls did nothing. | Actual connection status, membership roles, "Sent" status, working Files link, remove unsupported controls. |
| Files security | Client could change identity/size fields or register nonexistent/wrong-project objects. | Rename-only column grants and registration checks against Storage ownership/path/size metadata. |
| Files quota | Concurrent registrations could each pass the same quota calculation. | Lock the project before calculating the total. Tested two simultaneous registrations where only one fits. |
| Storage deletion | Direct deletion could remove a referenced object; an unqualified `name` in the guard resolved to the file's display name. | Explicit outer Storage name; require record removal before binary cleanup. |
| Files writes | RLS can return success with zero affected rows; overlapping upload batches could overwrite UI state. | Require returned mutation records; guard concurrent batches and use functional state updates. |
| UI | Duplicate overview tabs, back links, labels, and emoji/icon pairs. | Remove duplicates, retain Lucide and the new visual style; use native dialogs for keyboard focus/Escape. |
| Paper compiler | A nested main file produced a PDF but retrieval and BibTeX failed. | Worker-only root entry; real WASM regression test verifies references resolve. |
| Paper state | Opening file manager refreshed the tree but retained stale selected-file content/version. | Refresh the selection/draft from the same snapshot; never fall back to a folder as an editable file. |
| Import | Upload batches were read before checking total size/count; workers could remain alive on errors. | Check batch bounds first and terminate ZIP workers on all completion paths. |
